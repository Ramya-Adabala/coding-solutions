## Problem

### Logical Condition

Consider the following code. What will happen when the program is executed?

```
class Codechef {
    public static void main(String[] args) {
        int num = 5;
        while (num != 0) {
            System.out.println("This will never end");
            num++;
        }
    }
}

```
