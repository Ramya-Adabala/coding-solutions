## Problem

### Length of array items

Write a program to declare and initialise an array of strings and print the length of  **1st element**  and  **3rd element**  in same line with space in between. The strings are  **{"Code", "Chef", "C"}**.

## Solution

**Language:** JavaScript  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-30T03:18:23.254Z  

```js
const array = ["Code", "Chef", "C"];

// Print the length of first element.
let length1=array[0].length;
let length2=array[2].length;


// Print the length of third element.
console.log(length1,length2);
```
