## Problem

### Weather Station Data Tracker

Weather stations monitor  **temperature and rainfall**  to analyze climate patterns. Use  **`float`**  for temperature values with decimals and  **`double`**  for precise rainfall measurements.

 **Expected Output:** 

```
Temperature: 28.3 °C  
Rainfall Level: 125.6789 mm  

```

Run the code, modify values, and observe different weather conditions!

## Solution

**Language:** Java  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-10-27T00:41:46.889Z  

```java
class Codechef {
    public static void main(String[] args) {
        // Step 1: Declare and assign temperature (float)
        float temperature = 28.3f;  // Temperature in degrees Celsius

        // Step 2: Declare and assign rainfall level (double)
        double rainfallLevel = 125.6789;  // Rainfall in millimeters

        // Step 3: Print the weather data
        System.out.println("Temperature: " + temperature + " °C");
        System.out.println("Rainfall Level: " + rainfallLevel + " mm");
    }
}

```
