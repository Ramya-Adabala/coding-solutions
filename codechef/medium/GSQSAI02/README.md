## Problem

### Current date and time

Listen

Let's look into more date functions:

 **CURRENT_DATE**  - It returns the current date which is in the format ("YYYY:MM:DD"), (e.g. "2024-11-07")

- To get the current date, the following syntax is used:

```
  SELECT CURRENT_DATE;

```

 **CURRENT_TIME**  - It returns the current time which is in the format ("HH:MM:SS"), (e.g. "13:23:33")

- To get the current time, the following syntax is used:

```
  SELECT CURRENT_TIME;

```

### Task
- Write a query which outputs the current date(YYYY-MM-DD).
- Write a query which outputs the current time(HH:MM:SS).

 **Note:**  The output will be 5hrs 30min behind the local time.

## Solution

**Language:** SQL  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-14T10:25:36.258Z  

```sql
/* Write a query which outputs the current date.
   Write a query which outputs the current time.*/
   select current_date;
   select current_time;
```
