## Problem

### Print Another Pattern - MCQ

What would be the output of the following code:

```
#include <stdio.h>

int main() {
   printf("     *\n    **\n*** \n   \n  *");
}

```

### Options:

```
A. *
   **
   ***
     
     *

B.     *
      **
     ***
      
     *

C.   *
    ***
     *
    ***

D.    **         *

```
