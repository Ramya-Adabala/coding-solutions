## Problem

### Print Squares

Write a program to output the squares (using multiplication) of numbers from 1 to 5 on separate lines.

Input
Output

```

```
```
1 - 1  
2 - 4  
3 - 9  
4 - 16  
5 - 25  
```

## Solution

**Language:** c_cpp  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-10-03T04:32:01.267Z  

```c_cpp
#include <iostream>
using namespace std;

int main() {
    cout << 1 << " - " << 1 * 1 << endl;
    cout << 2 << " - " << 2 * 2 << endl;
    cout << 3 << " - " << 3 * 3 << endl;
    cout << 4 << " - " << 4 * 4 << endl;
    cout << 5 << " - " << 5 * 5 << endl;

    return 0;
}

```
