## Problem

### Divide two variables

Create a program to perform the following:

- Declare two integer variables a and b.
- Assign the value $20$ to a and $6$ to b.
- print the result of a / b.

## Solution

**Language:** c_cpp  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-10-03T04:34:55.182Z  

```c_cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    
    int a = 20;
    int b = 6;
    cout << a/b;

    return 0;
}

```
